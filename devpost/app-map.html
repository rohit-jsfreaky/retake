Retake: app map

A take-home guide to where things live. A snapshot of commit a625cd7 (26 Oct 2026); the code may move on after this.

What the app does

You paste a script, read it once, and Retake marks the words a listener would miss, for example fillers heard as "pillers". It has three main pieces: the page in your browser (recording and drawing the marks), one small server route that passes your audio to Deepgram (the listener), and the comparer in lib/, which lines up your script with what was heard.

One action, end to end: Stop → marked script

Reference route (3 stops)

A route to follow in your editor. Search for the names in code.

1Recording ends: components/useRecorder.ts

stop() turns the mic recording into a WebM/Opus Blob. app/practice/page.tsx → onTake receives it and calls listen() in lib/listen.ts.

2The listener: app/api/listen/route.ts

POST checks the body (audio, not empty, at most 5 MB), sends it to Deepgram with the key kept on the server, and returns only the words. A soundless file comes back as "No speech".

3The comparer: lib/marks.ts → markTake

It calls align() in lib/align.ts, a word-level edit distance that labels each word match, swap, missed or added. It then gives each step to its line, and markLine turns steps into marks. components/MarkedLine.tsx draws them.

A practice to reuse

Prove the risky outside service with one real call, then make what it returns visible. Slice 1 sent one real Chrome recording to Deepgram before any marking code existed (evidence/slice1-chrome-webm-call.json). That showed WebM is accepted and numbers come back as words, which led to the number fix in lib/lines.ts. Later, the first real take came back almost empty, and the marks alone couldn't explain why. Adding the recording player and the "What the listener heard" transcript made the cause visible: the mic, not the comparer (see Revisions in devpost/checklist.md). On another project with an external API, make one recorded real call first and show the raw response on screen while you build.

The tests that pin the comparer down

lib/align.test.ts, lib/lines.test.ts and lib/marks.test.ts cover one swapped word, a missing word, an added "um", a repeated word, numbers, pauses, speed and Ready. Run them with npm test.

Run it again

npm install, put DEEPGRAM_API_KEY=… in .env.local, then npm run dev and open http://localhost:3000. Live: https://retake-gules.vercel.app. Reopen this map by opening devpost/app-map.html in any browser.
